# Content scope

Definitions here are authoritative data with stable IDs. Never rename or reuse an ID silently; add a new ID or a migration entry. Keep values in the units the definition declares. Do not encode gameplay rules that belong in `docs/spec/` or code paths that belong in `src/`. Validate with `dotnet run --project tools/Sovereigns.Headless -- validate-content` after any change. Record the license of any media or dataset in `docs/legal/third-party.json`.
