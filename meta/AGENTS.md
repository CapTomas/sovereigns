# Routing metadata scope

Files here are machine-readable indexes of source Markdown, not separate authoritative gameplay specifications. Existing task IDs remain stable; phase Markdown is the source of task descriptions and completion checkboxes. After reviewed edits, run `python3 tools/update_manifests.py` and `python3 tools/validate_repo.py`; new task IDs require explicit scoped specification routing. Do not manually invent completed statuses in JSON indexes.
