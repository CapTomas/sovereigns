**Depends on:** 51 and all playable systems.  
**Outcome:** End-to-end campaigns are enjoyable, fair, stable and complete across diverse worlds.  
**GDB:** §§1–2, 25–26, 29–32, 37.

- [ ] **SOV-P52-T01** — Create a canonical full-game QA matrix covering world size, seed, climate, start type and difficulty.
- [ ] **SOV-P52-T02** — Create regression catalog for every GDB physical, economic, political and combat invariant.
- [ ] **SOV-P52-T03** — Run nightly worldgen seed batches and flag missing rivers, impossible geography or invalid cultures.

- [ ] **SOV-P52-T10** — Run siege cases: rationed fortress, harbor supply, relief force and damaged wall persistence.
- [ ] **SOV-P52-T11** — Compare manual and automatic battle outcomes across terrain, morale and unit compositions.
- [ ] **SOV-P52-T12** — Check faction AI never receives hidden information, instant money or physically impossible movement.
- [ ] **SOV-P52-T13** — Test viable playstyles: agricultural realm, mountain mining power, trade state and defense-focused kingdom.
- [ ] **SOV-P52-T14** — Check expanding kingdoms face plausible but not arbitrary administration and logistical costs.

- [ ] **SOV-P52-T18** — Test save-file integrity, upgrade migrations and restoration under simulated crash/low disk space.
- [ ] **SOV-P52-T19** — Audit localization placeholders, incorrect numeric units and missing pluralization cases.
- [ ] **SOV-P52-T20** — Validate random events are state-driven where required and documented as uncertain where not.
- [ ] **SOV-P52-T21** — Play full campaigns to achievement/defeat and hundreds of subsequent sandbox turns.
- [ ] **SOV-P52-T22** — Conduct reproducible bug triage with seed, turn, location, game build and recorded event history.
- [ ] **SOV-P52-T23** — Track all release-blocking regressions to closure with evidence and retest history.
