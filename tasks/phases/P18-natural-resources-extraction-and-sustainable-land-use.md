## Phase 18 — Natural resources, extraction and sustainable land use
**Depends on:** 17 and ecological resource stores.  
**Outcome:** Minerals, timber and other materials enter the economy through real production locations.  
**GDB:** §§6.5, 6.8, 12, 15.

- [ ] **SOV-P18-T01** — Define compact commodity catalog with units, perishability, storage and physical transport properties.
- [ ] **SOV-P18-T02** — Define spatial mineral deposits, accessible reserves, ore grades and extraction-site suitability.
- [ ] **SOV-P18-T03** — Define timber stands with exploitable biomass, regeneration and terrain-access restrictions.
- [ ] **SOV-P18-T04** — Define quarries, clay pits, pastures, fisheries and water-powered resource opportunities.
- [ ] **SOV-P18-T05** — Represent ownership, site workforce, equipment condition and input requirements for extraction.
- [ ] **SOV-P18-T06** — Create extraction facilities from physical locations and initial labor/capital.
- [ ] **SOV-P18-T07** — Simulate material production over time with resource depletion, transport and tool constraints.
- [ ] **SOV-P18-T08** — Deduct harvested timber from vegetation state, not an unrelated economic reservoir.
- [ ] **SOV-P18-T09** — Implement fuel and charcoal consumption for metal production as finite material flow.
- [ ] **SOV-P18-T10** — Implement first processing transformations (ore to iron, logs to timber/charcoal, grain to flour).
- [ ] **SOV-P18-T11** — Deduct both inputs and labor capacity when production occurs.
- [ ] **SOV-P18-T12** — Define production capacity separately from current utilization and actual output.
- [ ] **SOV-P18-T13** — Apply seasonal and physical disruption to sites: flooded mine, inaccessible quarry, burned forest.
- [ ] **SOV-P18-T14** — Allow damaged and exhausted resource sites to reduce output rather than silently respawn goods.
- [ ] **SOV-P18-T15** — Add regional production, deposits and sustainability overlays.
- [ ] **SOV-P18-T16** — Test chain interruption through fuel shortage and broken extraction routes.
- [ ] **SOV-P18-T17** — Test tools/fuel inputs and conservation across production transformations.
- [ ] **SOV-P18-T18** — Test rebuilding the same burned forest and quarry location after years of recovery/use.
- [ ] **SOV-P18-T19** — Establish reusable commodity balance diagnostics showing source and sink of every major good.

**Exit gate 18:** A settlement can mine, fell, process and store materials only from accessible, finite geographically grounded inputs.
