## Phase 43 — Production campaign UI, overlays, planning and information design
**Depends on:** 42 and all primary systems.  
**Outcome:** The enormous simulation is navigable as an understandable kingdom strategy game.  
**GDB:** §§26.1–26.6, 26.8, 26.11–26.13, 27.

- [ ] **SOV-P43-T01** — Define information hierarchy from kingdom overview to region, settlement, land parcel and army.
- [ ] **SOV-P43-T02** — Build final interaction contract for pan, zoom, select, inspect, compare and issue orders.
- [ ] **SOV-P43-T03** — Expose political borders separately from military presence, influence and legal claims.
- [ ] **SOV-P43-T04** — Create overlays for elevation, slope, land cover, temperature, rain, soil, snow, water and wind.
- [ ] **SOV-P43-T05** — Create economic overlays for harvest, food security, resources, trade, labor and market stress.
- [ ] **SOV-P43-T06** — Create operational overlays for roads, marches, supplies, crossings, fronts and blocked access.
- [ ] **SOV-P43-T07** — Build settlement panels with population, production, stores, local rights and current problems.
- [ ] **SOV-P43-T08** — Build treasury, tax and royal obligations views separating sovereign finance from private wealth.
- [ ] **SOV-P43-T09** — Build diplomacy interface with treaties, passage permissions, claims and war terms.
- [ ] **SOV-P43-T10** — Build construction UI with siting, available materials, progress and physical consequences.
- [ ] **SOV-P43-T11** — Build army creation, equipment, recruiting, deployment and supply planning UX.
- [ ] **SOV-P43-T12** — Build order preview with timing, route, uncertainties and opportunity costs.
- [ ] **SOV-P43-T13** — Build causal explanation from symptoms to sources: e.g., bridge failure to grain shortage.
- [ ] **SOV-P43-T14** — Prioritize alerts about irreversible outcomes, urgent battles, food crises and expiring obligations.
- [ ] **SOV-P43-T15** — Allow search for a settlement, army, fortress, route or important geographic location.
- [ ] **SOV-P43-T16** — Ensure all overlays indicate observation uncertainty, date and data provenance where relevant.
- [ ] **SOV-P43-T17** — Avoid overwhelming the player with environmental values unless they request deeper detail.
- [ ] **SOV-P43-T18** — Provide keyboard, mouse, screen-scale and display-setting controls independently of visual style.
- [ ] **SOV-P43-T19** — Validate tooltip and dashboard numbers against authoritative state, not duplicate UI calculations.
- [ ] **SOV-P43-T20** — Test decisions that require viewing both winter weather forecast and army route conditions.
- [ ] **SOV-P43-T21** — Run new-player usability sessions and cut redundant clicks for common strategic actions.

**Exit gate 43:** A new player can find a shortage, understand its cause, choose an intervention, view expected costs and verify consequences without reading debug data.
