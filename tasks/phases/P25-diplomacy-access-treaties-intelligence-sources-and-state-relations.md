## Phase 25 — Diplomacy, access treaties, intelligence sources and state relations
**Depends on:** 23 and political rights.  
**Outcome:** Multiple polities communicate, make binding agreements and retain imperfect knowledge.  
**GDB:** §§17, 20, 21, 25.3.

- [ ] **SOV-P25-T01** — Define diplomatic relations and formal state recognition independently from current military occupation.
- [ ] **SOV-P25-T02** — Define war, peace, alliance, neutrality, tribute, vassalage and trade relationship states.
- [ ] **SOV-P25-T03** — Define military access explicitly, including route classes, duration, supply permission and revocation.
- [ ] **SOV-P25-T04** — Allow requests, offers, acceptance, refusal and expiry of treaties with recorded obligations.
- [ ] **SOV-P25-T05** — Define territorial claims and surrender terms based on existing political and legal institutions.
- [ ] **SOV-P25-T06** — Introduce reputation, trust, grievance, threat and political interests as observable AI influences.
- [ ] **SOV-P25-T07** — Treat troops marching without permission as trespass with possible escalating consequences.
- [ ] **SOV-P25-T08** — Preserve allied passage as passage, not occupation or conquest.
- [ ] **SOV-P25-T09** — Define crossing access for supplies and civilian goods separately where treaties require it.
- [ ] **SOV-P25-T10** — Build initial fog-of-war knowledge from scouts, witnesses, roads, watchposts and settlements.
- [ ] **SOV-P25-T11** — Distinguish true world state from faction observation, memory and unreliable reports.
- [ ] **SOV-P25-T12** — Implement message delivery/reconnaissance delay and date-stamped intelligence.
- [ ] **SOV-P25-T13** — Allow rival faction to revoke access while an army is mid-transit; define legal/operational fallback.
- [ ] **SOV-P25-T14** — Allow occupation to be negotiated without destroying remaining sovereign institutions automatically.
- [ ] **SOV-P25-T15** — Allow peace to transfer claims or grant tribute without magically clearing armies from the map.
- [ ] **SOV-P25-T16** — Build diplomacy and access-route overlays visible to the player.
- [ ] **SOV-P25-T17** — Test the same road under ally access, neutral refusal and declared war.
- [ ] **SOV-P25-T18** — Test stale scout reports and new rain changing a march after the player receives a forecast.
- [ ] **SOV-P25-T19** — Test sovereignty restoration after foreign withdrawal from an otherwise unoccupied region.

**Exit gate 25:** Diplomatic permission determines legal transit and trade; neither allied movement nor military overflight of territory changes sovereignty or occupation.
