**Depends on:** 22 and stable world time.  
**Outcome:** The player can govern a kingdom over time, inspect consequences and use commands.  
**GDB:** §§2, 16, 26, 28, 29.

- [ ] **SOV-P23-T01** — Create campaign start flow with seed, world size, climate options and playable kingdom selection.
- [ ] **SOV-P23-T02** — Represent player allegiance to a continuing polity rather than one mortal ruler.
- [ ] **SOV-P23-T03** — Implement seven-day strategic turn planning and order submission.
- [ ] **SOV-P23-T04** — Advance the world chronologically inside the turn, running appropriate physical/economic cadences.
- [ ] **SOV-P23-T05** — Allow the turn to pause for meaningful encounters without rewinding weather or trade.
- [ ] **SOV-P23-T06** — Create turn-resume semantics after a battle, decision or interrupted operation.
- [ ] **SOV-P23-T07** — Implement selectable settlements, holdings, roads and armies with accurate inspection panels.
- [ ] **SOV-P23-T08** — Implement simple treasury, provisions, diplomacy and warning summaries in a temporary UI.
- [ ] **SOV-P23-T09** — Allow a kingdom-wide taxation policy and observe real effects after multiple turns.
- [ ] **SOV-P23-T10** — Create a direct royal building/transport project order (simple placeholder allowed only on GDB-consistent world state).
- [ ] **SOV-P23-T11** — Support basic administrative orders and automation for nonessential local tasks.
- [ ] **SOV-P23-T12** — Display exact campaign date/time and seasons across map and inspect panels.
- [ ] **SOV-P23-T13** — Display recent event log and causal notices for weather, construction and market shortages.
- [ ] **SOV-P23-T14** — Make campaign difficulty modify information and starting conditions, not world physics.
- [ ] **SOV-P23-T15** — Define first-game start and continuing polity defeat detection from actual political state.
- [ ] **SOV-P23-T16** — Add recoverable campaign save, abandon game and load flow for current integration scope.
- [ ] **SOV-P23-T17** — Test a multi-turn sequence with weather, birth/death, harvest and treasury effects.
- [ ] **SOV-P23-T18** — Test turn interruption followed by save/load, then consistent resumption.

**Exit gate 23 — Checkpoint E — First campaign loop:** A player can start a world, choose a kingdom, give orders, run multiple turns, observe meaningful world/economy changes and save/resume successfully.
